## 🚀 Projetos em destaque

### 🧠 WorkSense — TCC (FEI, 2026)
Ferramenta experimental de IA para identificar variações nos padrões de comunicação, interação e desempenho de perfis profissionais simulados.

- **Automação:** fluxo em **n8n** que recebe mensagens do Telegram, valida usuários e consome a **API do Trello** via requisições HTTP
- **Banco de dados:** **PostgreSQL dockerizado** em VPS, com modelo relacional + campos **JSONB** para preservar payloads brutos
- **IA conversacional:** agente com LLM open-source (**Ollama**, Qwen2.5-3B-Instruct) integrado ao Telegram
- **Análise em Python:** PLN com **spaCy**, análise de sentimentos e **Sentence Transformers**, com **Pandas/NumPy** para cálculo de scores comunicacional e profissional
- 🛠️ `Python` `n8n` `PostgreSQL` `Docker` `Ollama` `Telegram Bot API` `Trello API`

### 📱 Apps mobile com React Native (Expo Go)
- **App de farmácia:** catálogo por categorias e fluxo de pedidos/compra, com backend em nuvem (Supabase/Firebase)
- **App de lanchonete:** cardápio digital com pedidos integrado ao Firebase

### 🗄️ Integração entre bancos de dados
Sincronização bidirecional entre **MongoDB, Cassandra e PostgreSQL** em Python, com arquitetura própria de integração multi-banco.

### ☕ Java: POO e compiladores
- Sistema bancário com herança, encapsulamento e modelagem relacional no PostgreSQL
- Compilador que traduz uma linguagem inspirada em Minecraft para Pascal (análise léxica e sintática)

### 🎮 Jogos e minigames
- Jogo 2D de tiro ao alvo estilo *Aim Lab* no navegador (HTML + CSS + JavaScript)
- Air Hockey e Ping Pong na Unity (C#)
